# 提示词万能框架：角色 + 背景 + 任务 + 要求 + 示例

> 核心思路：把一句"随口的请求"，改造成一份"可执行的需求说明书"。
> AI 不会读心，你给的上下文越完整，输出就越贴近你要的结果。

---

## 一、框架速览

| 要素 | 作用 | 关键问句 | 常见失误 |
| --- | --- | --- | --- |
| 角色 | 决定 AI 的视角、知识结构与口吻 | 你现在是谁？ | 角色与任务不匹配（让"诗人"做财务分析） |
| 背景 | 补齐来龙去脉、受众与真实约束 | 为什么做？给谁看？ | 默认 AI 已经了解你的业务 |
| 任务 | 明确要 AI 执行的具体动作 | 具体做什么？ | 一句话里塞进三个任务 |
| 要求 | 规定格式、风格、字数、边界 | 做成什么样？不能做什么？ | 只说"写好一点、专业点" |
| 示例 | 给出可模仿的样板 | 照着什么抄？ | 要求"风格一致"却没给样例 |

---

## 二、五要素拆解

### 1. 角色（Role）—— 给 AI 一个身份
- 说明专业身份：资深律师 / 产品经理 / 语文老师 / 资深文案
- 说明经验与立场：十年经验、面向中小商家、风格偏保守
- 说明语气：冷静克制 / 轻松活泼 / 严谨正式
- 注意：角色要服务于任务。写法律意见书就别设定成脱口秀演员。

### 2. 背景（Background）—— 给足上下文
- 来龙去脉：发生了什么、为什么要做这件事
- 受众是谁：内部同事 / 客户 / 投资人 / 小学生
- 已有材料：原文、数据、历史版本、已知限制
- 成功标准：做到什么程度算好

### 3. 任务（Task）—— 清楚、具体、单一
- 用动词开头：撰写、改写、提炼、对比、评估、列出、润色
- 一次只做一件事，多件事就拆成多轮对话或编号多条
- 区分"只要结果"还是"也要思考过程"

### 4. 要求（Requirements）—— 做成什么样
- 格式：Markdown 表格 / 分点列表 / 邮件体 / JSON
- 风格：专业严谨 / 口语化 / 克制不夸张
- 字数：300 字以内 / 5 条要点 / 每条不超过 40 字
- 约束：不编造数据、不确定要说明、禁用某些词、必须覆盖某些点

### 5. 示例（Example）—— 参考样板
- 给 1～2 个"输入 → 输出"的样板，模仿效果远胜形容词
- 没有现成样板时，自己先写一句"理想版本"的开头
- 标明：哪些结构必须照抄，哪些内容可以自由发挥

## 三、可直接套用的模板

```markdown
# 角色
你是【身份】，擅长【领域】，风格【语气】。

# 背景
事情是这样的：【来龙去脉】
受众：【谁会看这份结果】
已有材料：【原文 / 数据 / 限制条件】
目标：【做完后要达成什么】

# 任务
请【动词】+【具体对象】。

# 要求
- 格式：
- 风格：
- 字数：
- 约束（必须做 / 不能做）：

# 示例
输入：……
输出：……
```

## 四、完整示例（改前 vs 改后）

改前（效果随机）：
```text
帮我写个产品文案。
```

改后（效果稳定）：
```markdown
# 角色
你是有 8 年经验的消费电子内容营销经理，文字简洁克制，不堆砌形容词。

# 背景
我们刚发布一款售价 199 元的桌面无线充电支架，目标受众是 20–30 岁上班族。
卖点：折叠便携、15W 快充、可同时给手机和耳机充电。
文案发在小红书，用户刷到后 3 秒内要产生兴趣。

# 任务
请写 3 版小红书种草文案的开头（正文前 2 行），供 A/B 测试。

# 要求
- 格式：3 个版本，每版不超过 40 字
- 风格：口语化、有画面感；不用"极致""颠覆""天花板"这类词
- 约束：不承诺未提及的功能；不使用 emoji

# 示例
参考风格：「通勤包里最占位置的，是充电器和数据线。」
```

## 五、进阶用法：想不清楚时，让 AI 反问你

当你自己也没想清楚需求，不要硬写提示词，直接在末尾追加一段"反问协议"：

```text
如果你对以上信息有任何不确定之处，不要直接开始作答。
请使用苏格拉底式提问法向我提问：
1. 一次只提一个问题；
2. 只问真正影响结果的关键信息（目标、受众、场景、约束、成功标准）；
3. 不要问提示词里已经写清楚的内容；
4. 根据我的回答继续追问，直到你判断信息足够；
5. 信息足够后，先用一句话复述你理解的需求，我确认后你再正式输出。
```

适用场景：写方案、做重要决策、需求还很模糊、对结果质量要求很高。

## 六、发出前的 30 秒自检清单

- [ ] 角色是否和任务匹配？
- [ ] 背景里是否包含受众、场景、已有材料、成功标准？
- [ ] 任务是不是一句话能说清的单一动作？
- [ ] 要求里是否写明格式、字数、风格、禁做事项？
- [ ] 有没有给示例？示例是否足够具体？
- [ ] 是否约定了"信息不确定时该怎么办"（说明局限 / 先反问）？

---

> 一句话总结：**角色定视角，背景定上下文，任务定动作，要求定边界，示例定标准；想不清楚的时候，让 AI 先问你。**
